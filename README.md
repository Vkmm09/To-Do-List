📌 About the Project

The To-Do List Application is a simple, command-line-based task management system developed using Python.

It helps users organize their daily activities by allowing them to add new tasks, view their task list, mark completed tasks, and remove tasks they no longer need.

The main purpose of this project is to make everyday task management easier while learning the fundamentals of Python programming.

✨ Features

This application provides five simple options:

Add a Task: Add a new task to your to-do list.

View Tasks: Display all your tasks along with their current status.

Mark as Done: Mark a task as completed once you finish it.

Remove a Task: Delete a task that is no longer required.

Exit: Close the application safely.

⚙️ How It Works

When you run the program, a menu appears on your screen.

You can select an option by entering its corresponding number.

For example:

Enter 1 to add a task.

Enter 2 to see all your tasks.

Enter 3 to mark a task as completed.

Enter 4 to remove a task.

Enter 5 to exit the application.

The program keeps running until you choose the exit option.

Task Status

Each task has one of two statuses:

❌ Not Completed: The task is still pending.

✅ Completed: The task has been finished.

🚀 How to Run the Project

Download and install Python from:

Step 2: Clone the Repository

Open your terminal and run:

Step 3: Open the Project Folder

Step 4: Run the Python File

The application will start, and you can begin managing your tasks!
